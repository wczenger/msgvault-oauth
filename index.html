msgvault

A personal email archive

A private, single-user tool. It reads the owner's own Gmail accounts (read-only) and keeps a copy on the owner's computer so the owner can search their own mail.

It is not a public service. It has no other users and no sign-up.

Privacy policy

  • Used only by its owner. There are no other users.
  • Gmail access is read-only (gmail.readonly). The tool never sends, changes or deletes mail.
  • Mail is stored only on the owner's computer. Nothing is sent to any server run by this app.
  • Nothing is sold, shared, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • You can revoke access at any time at myaccount.google.com/permissions.
